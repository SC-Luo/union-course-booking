## 2026-08-05 Logo 在 production 消失

現象：
production 顯示名稱已改為「課程管理系統」，但畫面沒有出現工會 logo。使用者指出 logo 之前已經做過，但這次 production 更新後消失。

判斷：
前一次 logo 相關變更存在於本機 `firestore-diagnostics-preview` 工作區的未提交檔案中，例如 `public/brand/*` 與 `src/lib/brand.ts`，但沒有進入 `main`。這次先前 production 更新是從乾淨 `main` 工作樹做最小 metadata 改名，因此只部署了 `main` 裡存在的檔案，未提交的 logo 變更沒有被帶上 production。

解法：
將 logo 原始檔正式複製到 `public/brand/union-logo-full.png` 與 `public/brand/union-logo-mark.png`，新增 `src/lib/brand.ts` 作為品牌設定單一來源，並讓 `layout.tsx`、`StudentShell`、`AdminShell` 與後台登入頁都引用這份設定。

後續改進：
品牌、logo、production 顯示名稱都必須納入 Git 並推到 `main`。後續 AI 若看到「之前做過但 production 不見了」，先查 `git status --short`、`git branch -vv`、`git diff --stat` 與未追蹤檔案，不要假設本機工作區內容已經等於 production。
